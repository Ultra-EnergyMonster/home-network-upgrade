# Router Configuration

## ISP Connection

The previous router's ISP connection settings were transferred to the new router to restore internet access.

Sensitive authentication details have been removed.

---

## LAN Configuration

The router gateway address was configured as:

# 192.168.50.1

This became the new local network address used to access the router management interface.

---

## Wireless Configuration

Configured:

- Existing WiFi network migration
- WiFi password transfer
- Separate 5GHz wireless network

Example:
HOME_WIFI
HOME_WIFI_5G

(Actual network names have been removed for privacy.)
