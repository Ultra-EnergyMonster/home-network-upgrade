# Testing & Verification

## Connectivity Testing

After installation, connected devices were tested to verify:

- Internet access
- WiFi connectivity
- Router access
- Stable connection

## Performance Testing

Speed tests were performed after installation using Ookla speedtest.

The previous router limited wireless performance due to older hardware. - (150Mbps)

The new AX5400 WiFi 6 router improved wireless throughput and allowed devices to better utilise the available 500Mbps internet connection. (^+350Mbps Increase)
