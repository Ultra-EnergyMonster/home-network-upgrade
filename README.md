# 🏠 Home Network Upgrade

## Overview

This project documents the upgrade of a home network from an old WR740N TP-Link router to a modern AX5400 WiFi 6 router.

The goal was to improve wireless performance, increase network capacity, and practise real-world networking configuration.

---

# 🔧 Hardware

## Previous Router
- TP-Link TL-WR841N
- Older WiFi technology
- Limited wireless throughput (150Mbps)

## New Router
- AX5400 Dual Band WiFi 6 Router
- Improved wireless performance
- Dual-band support (2.4GHz + 5GHz)

---

# ⚙️ Configuration Process

## 1. ISP Connection Setup

Recorded the existing ISP connection settings from the previous router and transferred the required authentication details to the new router.

> Sensitive ISP credentials have not been included.

---

## 2. Router Installation

Steps performed:

1. Disconnected the existing router
2. Connected the new AX5400 router
3. Accessed the router management interface
4. Verified network connectivity
